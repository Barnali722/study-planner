# study-planner
A web-based Student Study Planner built with Python Flask, SQLite & JavaScript. Features include color-coded subject management, session scheduling, a Pomodoro timer (25/5/15 min + custom), dashboard with daily stats, and one-click CSV export. No heavy frameworks — just clean, simple code.
